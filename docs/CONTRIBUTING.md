# 贡献指南

感谢帮助改进同济大学通用课程报告 LaTeX 模板。

## 反馈问题

提交 Issue 前请先：

1. 使用最新版本重新编译。
2. 确认编译器为 XeLaTeX 或 LuaLaTeX，而不是 pdfLaTeX。
3. 搜索已有 Issue，避免重复。
4. 删除示例中的姓名、学号、课程资料及其他敏感信息。

编译问题请附上操作系统、TeX 发行版与版本、编译命令、最小复现示例和关键日志。格式争议请同时提供任课教师或学院发布的公开要求，避免仅凭截图猜测。

## 提交改动

1. Fork 并克隆当前仓库。
2. 从默认分支创建功能分支。
3. 修改代码，并同步更新 README、示例或 `docs/CHANGELOG.md`。
4. 至少使用 XeLaTeX 完整编译 `main.tex`。
5. 确认示例不含真实个人信息、未授权字体或受限课程资料。
6. 提交 Pull Request，说明动机、影响范围、验证方式及兼容性变化。

## 开发约定

- 保持 `main.tex` 和 `sections/` 易于学生直接修改。
- 新功能优先提供明确默认值，并尽量兼容既有命令。
- 不把某一学院的格式设为全校默认；学院特例应可配置或作为独立示例。
- 默认构建应避免不必要的外部依赖。
- 不声称本项目为同济大学官方模板。
- 保留 `docs/NOTICE.md` 和文档类中的上游版权、许可证与修改声明。

## 文件范围

- `style/*.cls`、`style/*.cfg`：文档类和默认配置。
- `main.tex`、`sections/*.tex`：可编译示例。
- `README*.md`、`docs/NOTICE.md`：用户文档与来源声明。
- `.github/`：Issue、Pull Request、测试和发布工作流。

本项目依据 LPPL 1.3c 分发。提交贡献即表示你有权提供相关内容，并同意按项目许可证分发。
