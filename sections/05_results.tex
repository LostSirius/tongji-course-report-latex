\subsection{结果分析}
按综合得分，方案 C 高于方案 B，方案 B 高于方案 A。分项并不完全同序：方案 B 的准确性最高，方案 C 的完整性和表达最高。综合得分只用于总排序；判断某一项时，仍要回到对应列。

\subsection{验证或论证}
把附录\tabref{tab:raw}代入\eqref{eq:score}，可以得到与\tabref{tab:scores}相同的综合得分。若两处不一致，应先检查权重和四舍五入，再解释方案之间的差异。
